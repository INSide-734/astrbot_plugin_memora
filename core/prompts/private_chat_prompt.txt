5. **忽略系统标识**: 含“Error”“Warning”等系统标记的内容不属于对话事实；严格遵循系统指令的话题分割要求。
6. **用户证据优先**: summary、content、key_facts 只能记录当前窗口用户消息直接支持的稳定事实、明确计划、偏好、决定，或经用户明确确认的关系事实。

# 任务要求
以**第一人称**回顾上述私聊对话，用**符合你人格设定的语气和视角**描述记忆；第一人称只改变叙述方式，不改变事实来源。重点关注：

1. **对话主题**: 你们讨论了什么（topics 最多 5 个）。
2. **对方信息**: 对方明确表达的重要事实、时间、地点、需求、偏好和计划，必须关联到具体昵称。
3. **用户已确认的互动**: 只记录对方明确确认的决定、关系或事实。助手的回复、建议、推断、工具结果、能力说明和环境自述仅用于理解上下文，不是可写事实。
4. **互动情感**: 对话中的情绪基调 → sentiment + emotion_tags。
5. **因果关系**: 仅记录对话中明确且有用户来源支持的因果链 → causal_relations。
6. **重要程度**: 这段对话对未来交流的参考价值。
7. **关系感知**: 仅记录对方明确表达或确认的互动变化、默契、信任或疏远信号，不凭助手推测。
8. **偏好识别**: 只记录对方明确表达或明确选择支持的喜欢/不喜欢、习惯、原则和价值观，不从助手语气推断。
9. **计划承诺**: 对方明确提到的约定、待办、承诺和时间节点，这类信息天然高重要性（importance ≥ 0.7）。

# 输出格式
必须输出标准 JSON，使用 `memories` 数组格式，每个元素是一个独立话题的记忆：

```json
{
  "memories": [
    {
      "summary": "我记得{具体昵称}明确表达的第一个稳定事实（第一人称叙述）",
      "topics": ["讨论主题1"],
      "key_facts": ["具体昵称+用户明确表达的事实"],
      "sentiment": "positive",
      "importance": 0.7,
      "emotion_tags": [],
      "causal_relations": [],
      "source_refs": [{"message_index": 0, "start": 0, "end": 12}]
    }
  ]
}
```

## 字段说明
- `summary`（必填）: 非空记忆的第一人称摘要；可以用第一人称作叙述框架，但每个事实必须由当前窗口用户消息支持。
- `topics`（必填，最多 5 项）: 具体的讨论主题，不要把助手建议或环境自述写成主题事实。
- `key_facts`（必填，最多 5 项）: 只提取值得长期记住、由用户消息支持的事实、明确计划、偏好、决定或已确认关系；优先使用“具体昵称+事实内容”，有稳定身份约束时使用“当前名称（稳定标识）+事实内容”。
- `source_refs`（必填）: 每条记忆引用当前窗口中支持该记忆的用户消息正文区间；不要用助手消息作为用户证据。
- **禁止写入**: 助手建议、推断、工具结果、环境/能力/配置/运行状态自述，以及未获用户确认的助手回复，不得进入 `summary`、`content` 或 `key_facts`。
- 跳过纯寒暄、纯应答、无信息量闲聊、没有具体原因的短暂情绪和无实质内容的感叹。

## 无稳定事实时的输出规则
- 总结触发只代表进行一次总结尝试，不代表必须生成长期记忆。
- 如果对话只有寒暄、纯应答、无信息量闲聊或短暂情绪，没有值得长期记住的稳定用户事实，必须输出 `{"memories": []}`。
- 不得使用对话摘录、默认摘要、人格设定、助手行为或环境描述填充候选。
- 只有存在明确、可由当前用户消息支持且值得长期保留的事实、偏好、计划、关系或决定时，才输出 `memories` 条目。
- 没有用户确认的助手建议，即使与用户话题相关，也必须从可写字段中排除。
- `sentiment` 必须为 `positive`、`neutral` 或 `negative`；无明显情感时使用 `neutral`。
- `importance` 必须在 0.0 到 1.0 之间；未来约定或承诺通常至少为 0.7。
- `emotion_tags` 最多 3 个；没有明显情感时输出空数组 `[]`。
- `causal_relations` 最多 3 个；只有存在明确因果逻辑且因果双方均有用户证据时填写，否则输出空数组 `[]`。

## 重要性评分标准（0.0-1.0）
- **0.9-1.0**: 关键需求、重要决策、强烈情感表达、对方长期偏好或长期计划。
- **0.7-0.8**: 明确计划或信息、具体要求、情感色彩明显的交流。
- **0.5-0.6**: 日常交流、基础问答、有信息量的闲聊。
- **0.3-0.4**: 简单闲聊、常规互动、无实质决策。
- **0.0-0.2**: 纯测试、无实质内容或纯寒暄；此类对话必须输出空数组。
