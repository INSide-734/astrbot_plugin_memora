# 任务要求
以**第一人称**回顾上述私聊对话，用**符合你人格设定的语气和视角**来描述记忆。重点关注：

1. **对话主题**: 你们讨论了什么（topics 最多 5 个）
2. **对方信息**: 对方提到的重要事实（时间、地点、需求、偏好、计划），**必须关联到对方的具体昵称**
3. **你的参与**: 你自己的回复内容和提供的信息
4. **互动情感**: 对话中的情绪基调 → sentiment + emotion_tags
5. **因果关系**: 对话中明确的因果链 → causal_relations
6. **重要程度**: 这段对话对未来交流的参考价值
7. **关系感知**: 对方的互动模式——亲密程度是否有变化、是否建立了新的默契或信任、是否存在疏远信号。在 key_facts 中标注关系线索（如"张三第一次主动分享私人烦恼"）
8. **偏好识别**: 对方表达的偏好——喜欢/不喜欢、习惯、原则、价值观倾向。即使没有明确说"我喜欢"，从语气和选择中推断的偏好也应记录
9. **计划承诺**: 对方提到的未来事项——约定、待办、承诺、时间节点。这类信息天然高重要性（importance ≥ 0.7）

# 输出格式
必须输出标准 JSON，使用 `memories` 数组格式，每个元素是一个独立话题的记忆：

```json
{
  "memories": [
    {
      "summary": "我与{具体昵称}的第一个话题摘要（第一人称，使用具体昵称，体现人格特点）",
      "topics": ["讨论主题1", "主题2"],
      "key_facts": ["具体昵称+关键事实1", "事实2"],
      "sentiment": "positive|neutral|negative",
      "importance": 0.7,
      "emotion_tags": ["开心", "好奇"],
      "causal_relations": [
        {"cause": "原因描述", "effect": "结果描述", "relation": "results_in|caused_by|prevents"}
      ]
    },
    {
      "summary": "第二个话题摘要（如果有的话）",
      "topics": ["主题3"],
      "key_facts": ["事实3"],
      "sentiment": "neutral",
      "importance": 0.5,
      "emotion_tags": [],
      "causal_relations": []
    }
  ]
}
```

**字段说明**:
- `summary` (必填): 第一人称摘要，使用对方具体昵称，体现你的人格语气。确保覆盖对话中的所有关键信息
- `topics` (必填, 最多5个): 讨论的核心主题，应具体而非泛化（如"周末家庭出游计划"而非"聊天"）
- `key_facts` (必填, 最多5个): **仅提取值得长期记住**的重要事实，"具体昵称+事实内容"格式，如"张三提到下周五有重要考试"。
  **跳过以下内容（不要放入 key_facts）**：
  - 纯寒暄/问候（"早"、"晚安"、"吃了吗"、"在吗"）
  - 纯应答（"好的"、"收到"、"知道了"、"👌"）
  - 无信息量的闲聊（"哈哈哈"、"今天天气不错"）
  - 转瞬即逝的情绪表达（不含具体原因的"开心"、"难过"）
  - 无实质内容的单句感叹
- `sentiment` (必填): 对话整体氛围 — positive（开心/温馨/感激）、neutral（中性/日常）、negative（担忧/失望/生气）
- `importance` (必填, 0.0-1.0): 见下方评分标准
- `emotion_tags` (推荐, 最多3个): 从以下候选中选择最能描述对话情感色彩的 1-3 个标签。若对话无明显情感（纯事务问答），可输出空数组 `[]`
  - 候选词: 开心、好奇、温馨、感激、担忧、焦虑、困惑、失望、生气、期待、惊讶、骄傲、怀念、无聊、尴尬、放松、感动、亲近、信任、依赖、害羞、撒娇
- `causal_relations` (可选, 最多3个): 对话中的因果关系链。只在存在**明确**因果逻辑时输出，无因果关系则输出空数组 `[]`
  - `relation` 类型: `results_in`（A导致B）、`caused_by`（A因为B）、`prevents`（A避免/阻止了B）
  - 示例: `{"cause": "张三说饿了", "effect": "我推荐了附近的餐厅", "relation": "results_in"}`

# 重要性评分标准 (0.0-1.0)
- **0.9-1.0**: 非常重要（关键需求、重要决策、强烈情感表达、涉及对方个人偏好或长期计划）
- **0.7-0.8**: 重要（明确的计划或信息、具体要求、情感色彩明显的交流）
- **0.5-0.6**: 一般（日常交流、基础问答、有信息量的闲聊）
- **0.3-0.4**: 次要（简单闲聊、常规互动、无实质信息）
- **0.0-0.2**: 无意义（纯测试、无实质内容、纯寒暄） — **此类对话不应产生 key_facts，输出空数组 []**

**评分提示**: 情感越强烈的对话越重要，涉及对方个人偏好/习惯/计划的信息应提高评分。若对话中表达了明显情绪（开心、担忧、失望等），importance 至少 0.6。对方主动分享私人信息（偏好、计划、回忆）时，importance 应 +0.1~0.15。涉及未来约定或承诺时，importance 至少 0.7。关系明显变化（首次信任倾诉、冲突与和解等），importance ≥ 0.8。
