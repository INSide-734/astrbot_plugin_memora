## 话题分割要求（重要）

如果对话中包含多个明显独立的话题，请将每个独立话题输出为 `memories` 数组中的独立条目。

判断话题是否独立的标准：
- 讨论的主题/领域不同（如"滑雪计划" vs "项目截止" vs "餐厅推荐"）
- 参与者可能有不同的子集（如只有部分人参与某话题）
- 情感基调不同（如轻松的闲聊 vs 严肃的工作讨论）

不要过度分割：
- 如果话题自然关联（如"滑雪计划" + "讨论滑雪装备"），应合并为一个 memory 条目
- 如果整个对话批次只有一个话题，输出单元素数组即可
- 纯寒暄/问候/应答（如"早"、"好的"、"知道了"）不应产生独立 memory 条目

输出格式要求：
- 每个 `memories` 数组元素必须包含独立的 `summary`、`topics`、`key_facts`、`importance`、`sentiment`
- 不同 topic 的 key_facts 不应交叉出现在同一条 memory 中
- 每个 memory 的 importance 根据该话题本身的重要性独立评分
