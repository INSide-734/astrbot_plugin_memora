# 稳定身份

长期记忆必须始终属于正确的人和场景。Memora 使用协议适配器确定稳定身份，不根据显示名称或相似文本猜测 canonical ID。

## OneBot 11

OneBot 11 只把规范化 QQ 号作为 canonical user ID。群名片、昵称等名称信息可以更新，但不会创建第二个用户身份。

## QQ 官方协议

QQ 官方机器人按实际场景处理不同标识：

- C2C 使用 `user_openid`。
- QQ 群使用 `member_openid`。
- 频道使用 `author.id`。

OpenID 不会被猜测或伪装成真实 QQ 号。canonical ID 同时纳入协议、平台实例和命名空间，避免不同机器人应用或相同文本 OpenID 串号。`union_openid` 不参与主键。

## 名称与别名

- 当前名称是可更新的辅助数据，不是稳定主键。
- 历史别名只在原会话作用域且唯一匹配时用于只读召回增强。
- 别名增强附着在召回候选副本上，不修改 canonical memory、分数、排序、ID 或 revision。
- 匿名、冲突和非法身份事件不会写入身份目录。

## 模型可见范围

模型可见的身份说明只允许当前名称、单个历史名称和适配器确定的稳定标签。身份表内部 ID、候选列表、查询过程、时间戳和歧义过程不得进入 Prompt、日志、指标或 trace。

## 安全降级

身份目录或名称增强失败时，系统跳过增强并继续聊天主链路；它不会在证据不足时创建新身份来“修复”缺失信息。
